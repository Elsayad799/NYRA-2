NYRA AI v14 — Pydroid 3

1) Extract the ZIP.
2) Open Pydroid 3 terminal.
3) cd into the project folder.
4) Install:
   pip install -r requirements.txt
5) Copy .env.example to .env.
6) Put ONLY your Telegram bot token in TELEGRAM_BOT_TOKEN.
   Autonomous social behavior is enabled by default; set AUTONOMOUS_MODE=false if you want to pause it.
7) ADMIN_IDS is optional and should contain numeric Telegram IDs.
8) Run:
   python run.py

No OpenAI/Gemini/Groq/Claude API key is requested.
The supplied AI source adapters are bundled internally.

Media:
Telegram keeps the actual media. NYRA stores only useful metadata/observations.
Photos may be inspected temporarily in memory and are not archived locally.

Recovery:
NYRA retries its main Telegram loop after unexpected runtime failures with backoff.
Forced Android/Pydroid process termination, device shutdown, or a complete network/Telegram outage cannot be prevented by Python code.

Voice/Vision notes:
- NYRA now prefers Edge-TTS voice ar-EG-SalmaNeural (female Egyptian Arabic), then falls back to gTTS.
- Voice transcription prefers faster-whisper if you install it separately; otherwise SpeechRecognition remains the lightweight fallback.
- Image OCR is optional via pytesseract. Full visual reasoning needs an OpenAI-compatible multimodal VLM configured in NYRA_VISION_URL/MODEL; NYRA never pretends to see an image when no VLM is available.
- Music now keeps a Telegram file_id cache and can try YouTube first, then SoundCloud. It does not bypass anti-bot or access restrictions.
