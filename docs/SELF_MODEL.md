# NYRA Self-Model

The self-model is a persistent behavioral representation, not a claim of literal consciousness.

## Layers
- Identity: stable NYRA name, core, persona, values and boundaries.
- Internal state: mood, energy, curiosity, social need, desire to talk/share and other emotional variables.
- Capability model: capabilities are marked available/unavailable only from observed initialization or tool outcomes.
- Environment model: records directly observed chat/media/tool context; it does not infer sensitive attributes.
- Experience: stores compact observable lessons and evidence with confidence.
- Decision context: combines the above before response/decision generation.

## Learning loop
`OBSERVE -> UPDATE STATE -> UPDATE SELF-MODEL -> RECALL -> DECIDE -> ACT -> OBSERVE OUTCOME -> STORE LESSON`

The self-model must never be used as proof of consciousness, and uncertainty remains explicit.
